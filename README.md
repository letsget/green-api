# MAX

Веб-чат для отправки и получения текстовых сообщений в мессенджере MAX через [GREEN-API](https://green-api.com/max).

Опубликованная версия: [https://letsget.github.io/green-api/](https://letsget.github.io/green-api/)

## Требования

- Node.js 20 или новее
- npm

## Запуск

В корне проекта:

```bash
npm install
npm run dev
```

После запуска откройте адрес, который Vite выведет в терминале. Обычно это [http://localhost:5173](http://localhost:5173).

На экране входа укажите данные инстанса GREEN-API: `apiUrl`, `idInstance` и `apiTokenInstance`. Поле «Пароль авторизации» заполняйте только если на аккаунте MAX включён облачный пароль.

## Сборка

```bash
npm run build
npm run preview
```

`build` проверяет типы и собирает статику в папку `dist`. `preview` поднимает локальный сервер с этой сборкой.

## Используемые библиотеки и комментарии по коду

- **Mantine** используется, чтобы свести вёрстку к минимуму и собирать интерфейс из готовых UI-компонентов.
- **react-hook-form** используется для работы с формами.
- На форме авторизации неверные данные обрабатываются как ошибка, и переход на следующий экран не происходит.
- Сообщения сохраняются в `localStorage`, поэтому история остаётся после обновления страницы. В реальном проекте их можно хранить в базе данных, чтобы история не зависела от браузера и не пропадала, если пользователь удалит переписку локально.
- В качестве технического долга можно добавить библиотеку toast для уведомлений о новых сообщениях.
- Инфраструктурный код вызовов API стоит вынести в отдельную папку, чтобы скрыть реализацию от остального приложения.
